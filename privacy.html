Privacy Policy

Last updated: 19 November 2026

YouTube Autopilot is a personal tool run by its owner on the owner's own computer. It uses the YouTube Data API to upload videos and read statistics for the owner's own YouTube channel only.

Data it accesses

Through Google OAuth it accesses the owner's YouTube channel (upload videos, set titles, descriptions, thumbnails and scheduling, and read video and channel statistics). The OAuth token is stored locally on the owner's computer and is never shared.

Data it collects from others

None. The tool has no users other than its owner, no website accounts, no analytics and no cookies. It does not collect, store or share any personal data of viewers or other people.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Contact

Questions can be sent to the channel owner through the YouTube channel's About page.
